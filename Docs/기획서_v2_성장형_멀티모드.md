# 호스 킹덤 (Horse Kingdom) 기획서 — 말 왕국 마을 + 러시 런 원정

> 작성일: 2026-11-05 · 상태: 초안 v7
>
> **v7 변경점**
> - **게임 이름을 "호스 킹덤(Horse Kingdom)"으로 정함.** Unity 프로젝트·폴더 이름(`Animal Run`)과 코드 경로는 그대로 둔다.
> - **말과 동물만 남김.** 카드 동물은 당나귀·말·얼룩말에 새로 만들 조랑말·노새·짐말을 더한다. 영웅은 말 모양 판타지 동물 8종(기린 2종 제외). 대장은 **왕 말**.
>
> **v6 변경점**
> - **대장(플레이어 캐릭터)** 신설: 플레이어가 조작하는 캐릭터는 대장 하나다. 마을에서 직접 움직이고, 러시 런에서는 **무리 가운데**에 선다.
> - **영웅을 따로 분리**: 영웅은 새 테이블(`Heroes.tsv`)로 관리한다. **러시 런이 끝날 때 확률로 얻고**, 얻은 영웅은 **마을을 자유롭게 돌아다니다가 습격 때 같이 싸운다.**
> - 러시 런 무리 = 대장(가운데) + 시작할 때 고른 **카드 동물**. 문은 카드 동물 수만 바꾼다.
>
> **v5에서 이어지는 것:** 낮/밤 대신 **[⚔ 습격 시작] 버튼**으로 방어전을 시작한다. 울타리 디펜스 스테이지는 없다.
>
> **참고 영상**
> - 킹샷 소개 쇼츠(youtube.com/shorts/kQ5_rIm7tdM): 캐릭터를 드래그로 움직이며 자동 공격, 포털에서 나오는 적, 망루, 남은 적 수 표시.
> - 쓰론폴 플레이 영상(youtu.be/SF30x6B-Qz0, 0:00~6:42): 길게 눌러 짓는 건설 칸, 성 중앙(부서지면 패배), 방어를 버틴 집이 돈을 줌, 성 업그레이드 때 능력 고르기, 성벽, 병종 상성이 있는 막사.
>
> **원칙:** 참고 게임의 이름·그림체·캐릭터·건물 디자인은 가져오지 않는다. 장르 구조만 쓰고, 내용은 **말 왕국** 세계관과 Quirky 동물 아트로 채운다.

## 1. 한 줄 요약

**말 왕국의 마을을 키우고 지키는 게임.** 메인 화면이 곧 마을이다. 플레이어는 **대장**을 직접 움직여 건물(타워 등)을 짓고, 준비가 되면 **[⚔ 습격 시작]**을 눌러 쳐들어오는 적에게서 성을 지킨다. 건물 자원은 대장이 말 무리를 이끌고 나가는 **러시 런**에서 벌어 오고, 러시 런이 끝날 때 가끔 **영웅**이 마을에 합류한다.

```
        ┌─────────────────── 말 왕국 마을 (메인) ───────────────────┐
        │  🔨 준비: 대장이 건설·업그레이드, 영웅들은 마을을 돌아다님        │
        │        │                                                │
        │   [⚔ 습격 시작] ──▶ 습격: 대장 + 영웅 + 병사 + 타워가 함께 방어   │
        │        ▲                      │                         │
        │        └── 성공: 생산 보상·보석 ◀┘                         │
        └──────────▲───────────────────────────────┬─────────────┘
       지역별 자원  │  + 확률로 영웅 획득              │ 대장 성장, 건물 효과
        ┌──────────┴──────────┐                    │ (시작 무리 수, 대장 능력 …)
        │       러시 런 원정        │ ◀──────────────────┘
        │  대장(가운데) + 카드 동물 무리 │
        └─────────────────────┘
```

| 등장 캐릭터 | 무엇인가 | 어디에 나오나 | 어떻게 얻나 |
|---|---|---|---|
| **대장** | 플레이어 캐릭터. 하나뿐 | 마을(직접 조작), 러시 런(무리 가운데) | 처음부터 |
| **카드 동물** | 러시 런 무리를 이루는 평범한 동물 | 러시 런, 마을 막사 병사 | 처음 3종 + 목장에서 해금 |
| **영웅** | 특별한 동물. 이름·고유 스킬이 있음 | 마을(자유롭게 돌아다님), 습격 | **러시 런 종료 시 확률** |

### 3.1 `Animals.tsv` — 카드 동물만 남김

판타지 동물을 영웅 테이블로 옮기고, 평범한 말과 동물만 남긴다. 능력치 칸을 추가한다.

- **말과 동물만 남긴다.** 라마(3), 낙타(4), 쥐사슴(5), 누(6), 돼지(9)는 표에서 뺀다. 프리팹·스프라이트 파일은 지우지 않고 그대로 둔다(나중에 이벤트 등에 쓸 수 있게).
- 지금 있는 말과 평범한 동물(당나귀·말·얼룩말)은 모두 Medium이라 막사 3종을 채울 수 없다. 그래서 **조랑말(Small)·짐말(Large)**을 새로 만들고, Medium에 **노새**를 하나 더한다. 모델은 `make-animal` 스킬로 만든다.
- 시작 보유: **조랑말(Small) · 당나귀(Medium) · 짐말(Large)** — 크기가 달라서 막사 3종을 처음부터 채울 수 있다.
- ID는 지금 값을 그대로 두고, 새 동물은 18번부터 붙인다(저장 데이터·프리팹 경로가 바뀌지 않게).

## 4. 게임 구조

### 4.1 씬 구성

| 씬 | 내용 |
|---|---|
| `Boot` | 테이블·저장 데이터 불러오기 → `Village`로 이동 |

### 4.2 마을 — 준비 상태

```
┌──────────────────────────────┐
│ 🌾120 🪵80 🪨40 ⛓25 💎3  🛡 8단계 │
│                               │
│  [집]  (빈 칸 🪵10)   [사수 막사]  │ ← 빈 칸에서 길게 누르면 건설
│     🦄~~(돌아다니는 영웅)           │
│        ┌─────┐                │
│ [밭]   │ 성중앙│   [망루]         │ ← 성 중앙: 습격에서 부서지면 패배
│        └─────┘   🐴~~(영웅)      │
│      👑 ← 대장  🐴🐴 ← 병사      │
│ ▓▓▓▓ 성벽 ▓▓▓▓                 │
│ [원정 문]   ⛩ 다음 적: 북쪽·서쪽   │
│        ◯ 조이스틱               │
│ [건물][영웅 3/4]   [ ⚔ 습격 시작 ] │
└──────────────────────────────┘
```

- **대장 이동:** 드래그 조이스틱, 질주 버튼.
- **건설:** 정해진 건설 칸 위에서 길게 누르면 자원을 내고 짓는다. 칸마다 지을 수 있는 건물이 정해져 있다.
- **업그레이드:** 지은 건물 위에서 길게 누르면 업그레이드. 몇몇 건물은 갈래를 고른다(망루 → 궁수탑 / 투석탑).
- **영웅:** 마을을 **자유롭게 돌아다닌다**(4.4). 영웅을 누르면 정보·레벨업 창.
- **미리보기:** 다음 습격의 포털 위치와 적 구성.
- **러시 런 입장:** 원정 문으로 걸어 들어가거나 하단 버튼.
- **습격 시작:** 준비가 끝나면 **[⚔ 습격 시작]**. 누르기 전에는 적이 오지 않는다.

### 4.3 마을 — 습격

```
┌──────────────────────────────┐
│ ⚔ 8단계 습격   남은 적 23/40       │
│  ⛩ ← 적 포털        ⛩           │
│   적→→  ▓성벽▓  ←←적              │
│     🦄✨ ← 영웅 스킬    🏹망루      │
│   🐴🐴 👑 ← 대장이 적을 끌고 다님     │
│        ┌─────┐                │
│        │ 성중앙│ ███░ 체력          │
│        └─────┘                │
│  [💥특수 공격]       [📯병사 집결]  │
└──────────────────────────────┘
```

- 포털에서 적이 웨이브로 나온다(단계마다 2~5웨이브).
- **대장·영웅·병사·망루가 함께 싸운다.** 모두 자동 공격.
- 플레이어 조작은 대장 이동, **특수 공격**(쿨타임 있는 범위 공격), **병사 집결**(병사를 대장 위치로 부르기/돌려보내기).
- 적은 가까운 대상을 노린다 → 대장이 적을 끌고 다니며 시간을 벌 수 있다.
- 대장·영웅이 쓰러지면 성 중앙에서 몇 초 뒤 다시 살아난다.

### 4.4 영웅의 마을 행동

| 상태 | 행동 |
|---|---|
| **준비** | 마을 안을 자유롭게 돌아다닌다. 정해진 "쉼터 지점"(밭, 우물, 성 앞, 다른 영웅 옆) 사이를 천천히 걷고, 도착하면 잠깐 머물며 대기 동작(풀 뜯기, 하품, 다른 영웅과 마주보기). 대장이 가까이 가면 대장 쪽을 쳐다본다. |
| **습격 시작** | 가장 가까운 포털 쪽으로 이동해 자리를 잡는다. 플레이어가 영웅을 누르고 원하는 곳을 누르면 **그 자리로 보낼 수 있다**(선택 조작, 안 해도 알아서 싸움). |
| **습격 중** | 사거리 안 적을 자동 공격. 고유 스킬은 쿨타임마다 자동 사용. |
| **습격 끝** | 다시 준비 상태처럼 돌아다닌다. |

- **마을에 나오는 영웅 수 = 영웅 숙소 레벨 + 1** (최대 6). 나머지는 숙소에서 쉰다. 누가 나올지는 영웅 창에서 고른다.
- 영웅이 돌아다니는 모습이 마을을 "살아 있게" 만드는 핵심 연출이다. 새 영웅을 얻으면 바로 마을에 나타나게 한다.

### 4.5 습격 결과

| 결과 | 내용 |
|---|---|
| **성공** (적 전멸) | 살아남은 생산 건물마다 자원 + 보석 + 습격 단계 +1. 빨리 끝내면 보상 +20% |
| **실패** (성 중앙 파괴) | 부서진 건물은 무료 복구, 단계 그대로. 생산 보상 없음. 처치한 적 수만큼 약간의 보상 |

- 생산 건물은 **습격을 버틴 경우에만** 자원을 준다. 실시간 방치 생산은 넣지 않는다.

## 5. 자원

| 자원 | 주로 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 🌾 **식량** | 러시 런 **초원**, 습격 보상(밭) | 병사 보충, 카드 동물 레벨업(목장), 영웅 레벨업 |
| 🪵 **목재** | 러시 런 **숲**, 습격 보상(집) | 건물 짓기·업그레이드 |
| 🪨 **석재** | 러시 런 **채석장** | 성벽, 망루, 중반 이후 업그레이드 |
| ⛓ **철** | 러시 런 **광산** | 무기 레벨업(대장간), 막사 업그레이드 |
| 💎 **보석** (희귀) | 습격 성공, 각 지역 첫 클리어 | 카드 동물·무기 해금 |
| ✨ **영웅 조각** | 이미 가진 영웅을 또 얻었을 때 | 그 영웅의 승급 |

- 지역은 보상 자원과 **나오는 영웅**만 다르고 규칙은 같다. 청크 바닥·장식·적 외형을 지역마다 바꾼다.
- 지역 해금: 초원·숲(처음부터) → 채석장(성 중앙 Lv2) → 광산(성 중앙 Lv3).
- 기존 인게임 **코인은 판 안 경험치(증강용)로 그대로 두고**, 판이 끝나면 코인 수에 비례해 그 지역 자원을 추가로 준다.

**보상 공식 (초안)**
```
러시 런:  기본 보상 × (1 + 0.1 × (단계 - 1)) × 결과 배율
          결과 배율: 클리어 1.0 / 실패 0.3 × 도달 거리 비율
          지역 첫 클리어: 보석 +5
습격:     Σ(살아남은 생산 건물의 생산량) + 보석(1 + 단계/5)
          빨리 끝내기: × 1.2
```

## 6. 영웅 획득

### 6.1 러시 런 종료 시 판정

```
러시 런 끝 ─▶ 결과 화면(자원) ─▶ 영웅 판정
                                 ├─ 성공: 상자가 열리며 영웅 등장 연출 ─▶ 마을에 바로 나타남
                                 └─ 실패: "다음에 만날지도…" + 행운 게이지 상승
```

- **확률:** `HeroDrop.tsv`의 단계별 값. 예: 1단계 클리어 15%, 실패 5% / 20단계 클리어 25%.
- **등급:** 같은 표의 등급 비율로 정한 뒤, 그 등급에서 **이번 지역의 영웅(`Region`이 일치하거나 `any`)** 중 하나를 고른다.
- **행운 게이지(천장):** 영웅을 못 얻을 때마다 게이지 +1. **10이 되면 다음 클리어에서 확정**, 얻으면 0으로.
- **보너스 조건:** 결승선에 도착한 카드 동물 수가 많을수록 확률 소폭 증가 (`+ 0.1% × 도착 수`, 최대 +5%). → 무리를 크게 유지할 이유가 하나 더 생긴다.
- **중복:** 이미 가진 영웅이 나오면 **영웅 조각**(Rare 5 / Epic 10 / Legendary 20)으로 바뀐다.

### 6.2 영웅 성장

| 항목 | 내용 |
|---|---|
| 레벨 | 1 ~ 영웅 숙소 레벨 × 5. 식량으로 올림. 레벨당 체력·공격력 +6% |
| 승급 ★1~★5 | 영웅 조각으로 올림. 능력치 +20%, ★3에서 스킬 강화, ★5에서 스킬 효과 추가 |
| 무기 | 영웅마다 고정 무기(`WeaponID`). 무기 레벨은 대장간 레벨을 따름 |

| 성장 | **목장** | 카드 동물 레벨업, 새 카드 동물 들이기 | 카드 동물 체력·공격력 | 식량 (+보석) |

| 군사 | **막사** (종류 3개) | 카드 동물로 병사를 만듦 | **러시 런 시작 무리 수** | 식량·철 |

| 방어 | **망루** | 자동 공격 타워. 갈래: 궁수탑(빠름) / 투석탑(범위) | — | 목재·석재 |

### 7.1 성 중앙 능력 고르기

성 중앙을 올릴 때마다 3개 중 1개를 고른다(`SelectUI` 재사용). 고른 능력은 영구.

| 능력 예시 | 효과 |
|---|---|
| 자가 치유 | 대장이 싸우지 않으면 체력 회복 |
| 왕실 훈련 | 대장 공격력 +30% (마을·러시 런 모두) |
| 영웅의 부름 | 영웅 스킬 쿨타임 −20% |
| 든든한 벽 | 성벽 체력 +25% |
| 풍년 | 밭 생산 +1 |
| 원정 준비 | 러시 런 시작 무리 수 +2 |
| 행운의 편자 | 영웅 획득 확률 +3% |

### 7.2 막사와 병사

| 막사 | 들어가는 카드 동물 | 역할 | 강한 상대 | 약한 상대 |
|---|---|---|---|---|
| 사수 막사 | Small (조랑말) | 원거리, 체력 낮음 | 날아오는 적, 탱커 | 빠른 적 |
| 보병 막사 | Medium (당나귀, 말, 얼룩말, 노새) | 근거리, 균형 | 빠른 적 | 원거리 적 |
| 돌격 막사 | Large (짐말) | 원거리 공격을 덜 받음, 돌진 | 원거리 적 | 탱커 |

- 막사 레벨 = 병사 수(1~5). 습격에서 죽은 병사는 다음 준비 상태에서 식량으로 보충.
- **러시 런 시작 카드 동물 수 = 1 + 전체 병사 수 / 3** (최대 +10).
- 병사는 이름 없는 일반 동물, 영웅은 이름·스킬이 있는 특별한 동물로 역할을 나눈다.

## 8. 대장 (플레이어 캐릭터)

- 플레이어가 조작하는 캐릭터는 **대장 하나**다. 말 왕국의 무리를 이끄는 **왕 말** 콘셉트. 모델은 블렌더 Quirky 키트로 새로 만든다(예: 왕관과 붉은 망토를 두른 백마 — 다른 말과 한눈에 구별되게 갈기를 크게, 몸집은 Large).
- **무기:** 보유 무기 중 하나를 장착(대장간에서 성장). 특수 공격은 무기 계열에 따라 다름 — Gun: 연사 폭주 / Throwing: 회전 베기 / Rocket·Grenade: 큰 폭발.
- **성장:** 대장 레벨은 따로 없다. 무기 레벨 + 성 중앙 능력 + 성 중앙 레벨 보너스(체력 +10%/레벨)로 강해진다. (키울 곳을 늘리지 않으려는 의도)
- **러시 런:** 무리 가운데(0번 자리). 문의 영향을 받지 않는다. 체력이 0이 되면 실패.
- **마을:** 조이스틱으로 직접 이동, 건설, 습격 때 함께 싸움.

## 9. 러시 런 (원정)

### 9.1 무리 구성

```
           문(수식)  문(수식)
              │        │
         🐴 🐴 🐴 🐴 🐴
       🐴 🐴  👑  🐴 🐴     ← 👑 대장(왕 말): 항상 가운데, 1명
         🐴 🐴 🐴 🐴 🐴        🐴 카드 동물: 문을 지나며 늘고 줄어듦
```

- **대장:** 항상 **무리 가운데(나선 배치 0번 자리)**. 자기 무기를 쓴다.
- **카드 동물:** 시작할 때 **동물 카드 3장**(보유한 카드 동물 중 무작위). 고른 동물이 이번 판의 무리.
- **무기 카드:** 카드 동물의 무기는 지금처럼 무기 카드 3장(보유 무기 중)에서 고른다.
- **문:** 수식 결과대로 **카드 동물 수만** 바뀐다. 대장은 세지 않는다.
- **영웅은 러시 런에 나오지 않는다.** 마을과 습격 전용이다.

### 9.2 패배 조건

- 카드 동물이 0마리가 되어도 바로 지지 않는다. **대장 혼자** 계속 달린다.
- 적이 대장에게 닿으면 대장 체력이 줄고, **대장 체력이 0이 되면 실패**.
- 적은 가까운 러너부터 노리므로 바깥쪽 카드 동물이 대장의 방패가 된다.
- 카드 동물이 0마리일 때 "+" 문은 효과가 있고, "×"·"÷" 문은 효과가 없다.

### 9.3 진행

- 문으로 무리 수 조절 → 적 처치 → 코인으로 증강 → 결승선.
- 증강은 대장과 카드 동물 모두에게 적용. "무리 증원"·"무리 번식"은 카드 동물에 적용.
- 끝나면 **결과 화면(자원) → 영웅 판정 → 마을로 복귀**.

### 9.4 난이도 (지역마다 따로, 클리어할 때마다 단계 +1)

| 요소 | 규칙 |
|---|---|
| 적 체력 | `maxHP × (1 + 0.15 × (단계-1))` |
| 적 군체 수 | `EnemyGroup` 최대 5 → 단계마다 +1 (최대 15) |
| 적 등장 청크 | `firstEnemyChunkIndex` 2 → 10단계부터 1 |
| 문 수식 | 1~5단계 뺄셈 위주 → 6단계~ 방정식·거듭제곱↑ → 15단계~ 손해 문(÷, −)↑ |
| 거리 | 60~90초 → 단계마다 +3초 (최대 150초) |

## 10. 습격 난이도

| 요소 | 규칙 |
|---|---|
| 웨이브 수 | `2 + 단계/4` (최대 5) |
| 적 수 | `10 + 단계 × 3` (전체) |
| 적 체력 | `× (1 + 0.12 × (단계-1))` |
| 포털 수 | 1~4단계 1개 → 5단계 2개 → 10단계 3개 |
| 적 종류 | 3단계 빠른 적, 6단계 원거리 적, 9단계 탱커, 5단계마다 보스 |
| 빨리 끝내기 기준 | `60 + 단계 × 5`초 |

- **성 중앙 레벨이 모든 진행의 상한이다.** 예: 성 Lv3 → 습격 15단계, 러시 런 각 지역 15단계까지.
- 준비 화면과 원정 문에 **추천 전투력**을 보여 준다. `전투력 = 대장 + 영웅 + 병사 + 성벽·망루` 단순 합.

| **1. 뼈대** | Boot/Village 씬, 저장, 자원 표시, 러시 런 결과 → 마을 복귀 | 러시 런 한 판 하면 자원이 쌓이고 껐다 켜도 남음 |
| **2. 대장 + 러시 런** | 대장 모델(임시로 기존 동물), 무리 가운데 대장, 카드 동물만 문 영향, 대장 체력 패배 | 문을 지나도 대장은 그대로, 카드 동물만 늘고 줆 |
| **3. 테이블 분리 + 영웅 획득** | `Animals.tsv` 정리, `Heroes.tsv`·`HeroDrop.tsv`, 결과 화면 영웅 판정 | 러시 런이 끝나면 확률로 영웅을 얻고 저장됨 |
| **4. 마을 준비** | 대장 조작, 건설 칸, 성 중앙·집·밭, **영웅 돌아다니기** | 얻은 영웅이 마을을 돌아다님 |
| **5. 습격** | 습격 시작 버튼, 포털·웨이브, 성 중앙 패배, 보상, 망루·성벽, **영웅 전투·스킬** | 영웅과 함께 습격을 막으면 자원·보석이 들어옴 |
| **6. 병사·성장·지역** | 막사 3종, 목장·대장간·영웅 숙소, 성 능력, 지역 4종 | 키운 만큼 두 모드가 쉬워짐 |
| **7. 밸런스** | 자원 곡선, 영웅 확률, 단계별 적 구성 | 한 지역만 돌면 막히고 고루 돌면 잘 큼 |

**아트 작업 메모:** **대장 모델 1개**(왕 말), **카드 동물 3종**(조랑말·노새·짐말 — 2단계 전에 조랑말·짐말이 있어야 시작 동물이 갖춰짐), **마을 건물**(성 중앙, 집, 밭, 방앗간, 목장, 대장간, 영웅 숙소, 막사 3종, 성벽, 망루 2갈래), **러시 런 지역 4종의 바닥·장식**. 영웅은 이미 있는 말 모양 판타지 모델 8종으로 시작할 수 있다.

## 14. 정해야 할 것

1. 대장(왕 말)의 생김새 — 왕관 쓴 백마(추천)로 할지, 다른 색·장식으로 할지.
2. 영웅 획득 확률·천장(10회) 수치가 적당한지.
3. 영웅을 러시 런에도 데려갈 수 있게 할지 — 지금 안은 마을·습격 전용.
4. 러시 런 카드 동물의 무기를 무기 카드로 고를지, 대장 무기를 같이 쓸지.
5. 습격 실패 벌칙 — 지금 안은 "생산 보상 없음 + 같은 단계 다시".
6. 건물 아트를 블렌더로 직접 만들지, 에셋을 쓸지.

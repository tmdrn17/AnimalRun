# UI 디자인 프롬프트 — 호스 킹덤 러시 런 3택1 선택 카드

> 원본 틀: "UI · 디자인 프롬프트 작성법"의 화면 디자인 요청 틀을 AnimalRun(호스 킹덤) 기준으로 채움.
> 대상 화면: `SelectUI` — 동물 선택 · 무기 선택 · 증강 선택 패널(카드 3장 중 1장).

## 프롬프트 (Gemini · ChatGPT 공통)

```
모바일 러너 게임의 "카드 3장 중 1장 고르기" 선택 화면 UI를 디자인하고 싶어.

보는 환경: 세로 모드 스마트폰(1080 × 1920, 9:16). 엄지로 한 손 조작. 게임 화면 위에 반투명하게 덮이는 팝업 패널.
게임 분위기: "호스 킹덤" — 말 왕국 판타지. 동그랗고 귀여운 로우폴리 3D 말 캐릭터(당나귀 · 말 · 얼룩말 · 페가수스 · 유니콘)가 무리 지어 달리며 무기로 적을 쏘는 캐주얼 러너. 밝고 경쾌한 톤.
지금 상태: 화면 가운데에 카드 버튼 3개가 있고, 각 카드에 그림 1장 · 이름 · 설명 한 줄만 있는 단순한 구조. 같은 틀을 세 번 씀 — ① 시작 동물 고르기 ② 무기 고르기 ③ 달리는 중 레벨업 증강 고르기.

들어갈 정보(카드 1장당):
- 그림(동물 또는 무기 아이콘, 정사각형)
- 이름 (예: 얼룩말 / 석궁 / 연사 강화)
- 설명 한 줄 (예: "공격 속도 +15%", "러너 +3")
- 종류 표시: 동물 크기(소형·중형·대형) / 무기 계열(투척·총·로켓·투척폭발) / 증강 계열(무기 강화·무리 강화)
- 패널 위쪽 제목 (예: "함께 달릴 동물을 고르세요", "무기를 고르세요", "레벨 업! 강화를 고르세요")

참고: 모바일 로그라이크 게임의 레벨업 3택1 카드 화면의 "배치 구조와 정보 순서(그림 → 이름 → 효과)"만 참고.
단, 특정 게임의 색 · 테두리 장식 · 아이콘 · 로고 모양은 따라 하지 말고, 말 왕국(편자 · 왕관 · 갈기 · 깃발 모티프)에 맞게 새로 만들어 줘.

바꿀 것:
1. 카드마다 종류를 색과 작은 마크로 구분 (무기 강화 / 무리 강화가 한눈에 갈리게)
2. 효과 숫자(+15%, +3)를 크고 굵게 강조
3. 엄지로 누르기 쉬운 큰 카드, 누를 수 있다는 느낌(살짝 떠 있는 그림자)

지킬 것:
- 카드 3장 가로 한 줄 배치, 그림 칸은 정사각형 1:1
- 한글 텍스트가 잘 읽힐 것(이름 최소 큰 글씨, 설명은 한 줄)
- 뒤의 게임 화면이 살짝 보이는 반투명 어두운 배경

결과물: 세 화면(동물 고르기 · 무기 고르기 · 증강 고르기)을 한 장에 나란히 놓은 UI 목업 이미지 1장을 만들어 줘. 그리고 색 규칙(종류별 색)과 배치 설명을 짧게 표로 정리해 줘.
실제 적용(유니티 코드 · 에셋)은 내가 샘플을 확인한 다음에 할 거야.
```

### 새로 그려야 할 스프라이트 (글자 없이)

- **공통:** 카드 테두리 1장(흰색 9-slice, 색은 Image.color로 입힘), 제목 리본(9-slice), 왕관 장식, 편자 장식, 태그 바탕(둥근 알약형)
- **배지 아이콘:** 왕관(동물), 총 · 로켓 · 투척폭발 계열 마크, 무기 강화 · 무리 강화 마크
- **이미 있는 것(새로 안 그림):** 동물 그림 `Sprites/Runners/*_Image`, 무기 그림 `Sprites/Weapons/*_Image`. 증강 그림은 지금 코드처럼 무기 · 동물 그림을 그대로 씀(`AugmentDef.IsRunnerAugment`).

### 프로젝트에 맞출 점

- 현재 `SelectUI`의 `ButtonElement`는 그림 · 이름 · 설명 3개뿐 → 배지 Image, 태그(바탕 + 글자), 테두리 Image 참조를 추가해야 함.
- 현재 글자는 `UnityEngine.UI.Text`(레거시). ChatGPT는 TextMeshPro 기준으로 제안함 → 바꿀지 결정 필요.
- 카드 테두리는 흰색 스프라이트 하나 + 화면별 색 지정으로 처리하면 그림 3벌을 따로 만들 필요가 없음.
